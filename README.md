### 1. 프로젝트 소개

햄버거 가게 키오스크를 모방하여 만든 Spring 6기 과제입니다.

### 2. 개발환경

- Java 17.0.14
- IntelliJ IDEA 2024.3.3

### 3. 주요기능

- 햄버거 및 음료수 선택 기능
- 장바구니 기능 및 구입 기능
- 소비자 별 할인률 적용
